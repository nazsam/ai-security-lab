# Contributing

Defensive contributions welcome — new guardrail patterns, mitigations, or framework mappings.

- **Defensive only.** No working exploits or attacks against third-party systems. Test payloads must
  be benign strings used to validate your *own* defenses.
- Map new content to OWASP LLM Top 10 / MITRE ATLAS / NIST AI RMF where relevant.
- Keep code standard-library where possible so examples run without setup.
- No secrets or real customer data.

Small, focused PRs. MIT-licensed; educational reference, not a complete security solution.
